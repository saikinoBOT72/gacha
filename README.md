## これは何か

「ソシャゲのガチャ」を構成しているものは、抽選そのものではありません。
プレイヤーが体験しているのは、**結果を知るまでの数秒間に情報がどう開示されるか**です。

本プロジェクトは、その情報開示プロセス＝**演出**を分解し、
演出・雰囲気・効果音・気持ちよさを最優先事項として再構築したものです。

- **課金要素は一切ありません。** 通貨はすべてゲーム内無償で、現金価値もありません。
- **確率操作は行っていません。** 天井・ソフト天井・50/50 はすべて事前開示された仕様です。
- **提供割合を全件開示しています。** さらに「あなたの現在の実確率」まで表示します。

## 遊ぶ

ES Modules を使うため、`file://` ではなく HTTP で開く必要があります。

```bash
git clone <this repo> && cd gacha
python3 -m http.server 8777    # もしくは  npx serve .
# → http://127.0.0.1:8777/
```

**ヘッドホンを推奨します。** 40Hz 帯のサブベースまで含めて設計しています。

## 実装されているもの

### 演出

- **期待度の階段**：予兆 → 投入 → 詠唱 → 色の確定 → 昇格 → 解放 → カットイン → 顕現 → 余韻
- **オーラ色による期待度コード**：白 / 青（★2以上）/ 銀（★3以上確定）/ 金（★4以上確定）/ **虹（★5確定）**
- **昇格演出**：一度決まった色が、タメ（無音）のあと「バチバチ」と上の色へ。最大4段（白→虹、約3%）。
  段ごとに音色が変わる（`crackle1/2/3`）
- **金からの★5**：金オーラは「★4以上確定」。6% の確率で金のまま★5が出る
- **特殊ゲート**：★5限定 3%。画面が暗転し星が降る、実質の確定演出
- **★5専用カットイン**：レターボックス、速度線、紋章シルエット、名前スラム、「確定」印
- **10連**：扇状の一斉射出 → 天空爆散 → 配り（ピッチをばらけさせた着地音）→
  **裏面色によるヒント** → 裏面昇格 → タップ/一括めくり → **最良札は必ず最後**
- **クライマックス昇華**：10連の最後が★5なら、陣を再点火して昇格込みのフル演出へ
- **時間操作**：ヒットストップ（★5で110ms）、スローモー、スラムズーム、カメラ回り込み
- **ポストエフェクト**：トラウマ型画面揺れ（2乗則＋微回転）、色収差、光柱、衝撃波、十字フレア

### 音（すべてその場で合成）

- マスターリミッタ、3バス（BGM/SFX/UI）、**プログラム生成のインパルス応答**による
  ホール(3.6s)/ルーム(0.45s)/プレート(1.5s)の3種リバーブ
- 合成プリミティブ：FM / デチューンスタック / 膜鳴（和太鼓）/ Karplus-Strong（撥弦）/
  フォルマント合唱 / グレイン / 擬似シェパードのライザー
- インパクトは必ず **トランジェント＋ボディ＋テイル** の3層構成
- 虹の確定音：サブ → 合唱 → オケヒット → 和太鼓三連 → ベルの降り注ぎ
- **★5では BGM を完全に停止**してから合唱で戻す（量ではなく質で断絶させる）
- アダプティブ BGM：D エオリアン / BPM72 / 6レイヤーを画面状況でクロスフェード

### ガチャ仕様（全て画面上で開示）

| 項目 | 値 |
|---|---|
| ★5 基礎提供割合 | 0.600%（ピックアップ 0.300% ＋ 恒常 0.300%） |
| ★5 ソフト天井 | 74連目から 1連ごとに +6.0% |
| ★5 ハード天井 | 90連 |
| ★5 実効確率 | 約 1.61%（平均 62.3 連で1体） |
| ★4 基礎提供割合 | 5.100% / 10連保証 |
| ピックアップ | 50/50。すり抜けたら次は確定 |
| 天井引き継ぎ | 同種バナー間で引き継ぎ |
| 最終天井 | 1連ごとに「祈刻」1枚、200枚でピックアップ★5と確定交換 |

### その他

- 星霊 **86体**。ビジュアルは seed から決定的に生成される SVG 紋章（対称数・コア形状・
  リング・ルーン・翼・光輪を独立に振るので全員別の見た目になる）
- 図鑑 / 交換所（祈刻・星片）/ 履歴 / 統計（実測確率の開示）/ 実績27種 / デイリー
- 設定：音量3系統、演出スキップ、描画品質、**控えめモード**、フラッシュ低減、触覚

## 設計の芯

```
[ gacha.js ] ──結果──> [ stagePlan.js ] ──演出プラン──> [ ui/summon.js ]
   抽選のみ               結果から逆算              再生のみ
   演出を知らない          演出を組む               抽選を知らない
```

**抽選と演出を構造的に分離**しています。`gacha.js` は演出という概念を持たないので、
「演出が結果を左右する」ことは原理的に起こりません。

さらに、オーラ段階（tier）は **「下限の宣言」** として定義されています。

> tier2（銀）＝ ★3以上確定 / tier3（金）＝ ★4以上確定 / tier4（虹）＝ ★5確定

この不変条件（宣言した下限は必ず守られる）は `tests/stageplan.test.mjs` で
30万件の試行を使って検証しています。**演出は嘘をつきません。**

## テスト

```bash
node tests/run.mjs
```

依存ゼロのテストランナーで 34 件。主なもの：

- 100万連の統計検証（実効確率・50/50 が 2/3 に収束すること・天井が必ず発火すること）
- ★5間隔の最頻値がソフト天井域（74〜82連）にあること
- 演出プランの不変条件（宣言した下限が破られないこと、昇格が1段ずつであること）
- 10連の最良札が必ず最後に来ること、かつ順序が常に昇順ではないこと
- 壊れたセーブデータからの復帰

## 倫理方針

1. 実課金・課金導線を一切実装しない
2. 確率操作をしない。ピティは全て事前開示された仕様
3. 全レアリティ・全ピックアップの提供割合を開示する
4. 天井までの残回数とすり抜けフラグを常時可視化する
5. コンプガチャ型（複数収集で別報酬）を実装しない
6. ダークパターン（偽のカウントダウン、離脱阻止、煽り通知）を使わない
7. 光過敏性発作への配慮を実装し、初回に注意喚起する
8. 実在の作品・キャラクター・音楽を一切使わない

詳細は [`docs/NOTES.md`](docs/NOTES.md) A章・B章を参照してください。

## 技術的な制約

- ブラウザの制約により、**最初のタップ／クリックまで音は鳴りません**（AudioContext の解禁）
- 外部リクエストは 0 件。オフラインで完全に動作します
- 対応：Chrome / Edge / Firefox / Safari 16.4+（色収差の合成には `ctx.filter` を使用）
