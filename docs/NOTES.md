# 注意書き（実装中に絶対に守ること / 落とし穴集）

`docs/PLAN.md` の付属文書。実装中はこのファイルを都度参照する。

## A. 倫理・法務（最上位。ここを破ったら全てが無効）

| # | ルール | 理由 |
|---|---|---|
| A1 | **実課金導線を一切作らない。** 「石を購入」ボタン、価格表示、外部決済リンクを置かない | 本作は体験シミュレータ。射幸心を実消費に接続しない |
| A2 | **確率操作をしない。** 抽選は `gacha.js` の公開ロジックのみ。演出は結果を変えない | RESEARCH §2.7。構造的に分離する |
| A3 | **提供割合を全レアリティ・全ピックアップについて画面上で開示** | JOGA/CESA 自主規制の中核要件 |
| A4 | **天井までの残回数・すり抜けフラグを常時可視化** | 不安の解消。ダークパターンの反対側に立つ |
| A5 | **コンプガチャ型を実装しない**（複数種の収集で別報酬を出す構造） | 2012年に景表法「カード合わせ」として規制済み |
| A6 | **偽の緊急性を作らない**：偽カウントダウン、偽の他人の引き実績、離脱阻止モーダル | ダークパターン |
| A7 | **「あと少しで天井です」型のプッシュ/煽り通知を出さない** | 同上 |
| A8 | トップと設定に **「これはシミュレータであり実在の賭博ではない」** と明記 | 誤認防止 |
| A9 | 実在のゲームタイトル・キャラクター・ロゴ・音楽を一切使わない。**完全オリジナル** | 権利侵害の回避 |

## B. 健康・アクセシビリティ

| # | ルール |
|---|---|
| B1 | **光過敏性発作（PSE）配慮**：毎秒3回を超える全画面フラッシュを出さない。フラッシュは「1回の強い白 → 減衰」で表現し、連打しない |
| B2 | 赤の強い高輝度点滅を避ける（白／シアン／金を使う） |
| B3 | 初回起動時に **PSE 注意書き** を表示し、「演出を控えめにする」を1タップで選べるようにする |
| B4 | `prefers-reduced-motion: reduce` を検出したら、**自動で演出短縮モード**（フラッシュ無し、シェイク無し、遷移 80ms）で起動する |
| B5 | レア度を **色だけで表現しない**。★の数、ラベル（N/R/SR/SSR/UR）、枠の形状で冗長化 |
| B6 | 音量は BGM/SFX/UI の3系統 + マスターミュート。設定は永続化 |
| B7 | キーボード操作：`Enter/Space`＝決定、`Esc`＝戻る/閉じる、`S`＝スキップ、`Tab`＝フォーカス移動、`focus-visible` の可視リング |
| B8 | 全ボタンに `aria-label`。モーダルは `role="dialog" aria-modal="true"` + フォーカストラップ + 復帰 |
| B9 | タップ領域は最低 44×44 CSS px |
| B10 | 画面読み上げ向けに、結果は `aria-live="polite"` のテキストでも通知する |

## C. パフォーマンス（60fps を落としたら「気持ちよさ」は死ぬ）

| # | ルール |
|---|---|
| C1 | **パーティクルは必ずプール**。`new` をループ内で呼ばない。配列も再利用（`length = 0` ではなく生存インデックス管理） |
| C2 | Canvas は **DPR を上限 2 にクランプ**。4K で 3倍描画して死ぬのを防ぐ |
| C3 | Canvas レイヤは3枚まで（bg / fx / post）。レイヤを増やすほど合成コストが乗る |
| C4 | `shadowBlur` は極めて重い。グロー表現は **放射状グラデーション or 加算合成（`globalCompositeOperation='lighter'`）** で代替 |
| C5 | `filter: blur()` を大面積の DOM に常時かけない。演出の瞬間のみ |
| C6 | DOM アニメは `transform` / `opacity` のみ。`width/height/top/left` を触らない |
| C7 | 大量 DOM（カード86枚の図鑑など）は `content-visibility: auto` + `contain: layout paint` |
| C8 | RAF ループは1本。各サブシステムは `update(dt)` を受ける |
| C9 | `dt` は 1/30 秒でクランプ（タブ復帰時の大ジャンプ対策） |
| C10 | 実 fps を計測し、45fps を下回ったら自動で品質を1段下げる（パーティクル数 60%、ブラー無効） |
| C11 | 画面遷移時に **RAF / AudioNode / addEventListener / setTimeout を必ず解除**。`AbortController` を screen ごとに持つ |

## D. Web Audio の落とし穴

| # | ルール |
|---|---|
| D1 | `AudioContext` は **最初のユーザー操作で `resume()`**。それ以前に作った音は鳴らない |
| D2 | 発音は `ctx.currentTime + 0.02` 以降にスケジュール（0 ちょうどはクリックノイズの原因） |
| D3 | ゲインを `0` にしない（`setValueAtTime(0)`→指数ランプが動かない）。**最小値 0.0001** を使う |
| D4 | `exponentialRampToValueAtTime(0, …)` は例外。必ず `0.0001` へ |
| D5 | 鳴り終わった `OscillatorNode` は `onended` で `disconnect()`。放置するとノード数が爆発する |
| D6 | 同時発音数に上限（例 48）。超えたら最古を停止 |
| D7 | 同名SFXの最小再発火間隔（例 25ms）を設けて、連打による音圧の爆発を防ぐ |
| D8 | ノイズバッファは **起動時に1度だけ生成して再利用**（毎回生成するとGCが跳ねる） |
| D9 | リバーブ IR も起動時に1度生成。生成は 3.6秒 × 48kHz × 2ch ＝ 実測数十msかかるので、スプラッシュ中に行う |
| D10 | サブベース（40–60Hz）は **リミッタ前で -6dB 程度に抑える**。スマホでは聞こえないが、PCでは歪む |
| D11 | iOS では `webkitAudioContext` と、サイレントスイッチで鳴らない問題がある。`<audio>` の無音再生でアンロックする手法を併用 |
| D12 | タブが非表示になったら `suspend()`。復帰で `resume()` |

## E. 演出（設計上のアンチパターン）

| # | ルール |
|---|---|
| E1 | **演出から結果を漏らさない**（意図した「色ヒント」以外で）。例：★5のときだけ処理が重くなる、DOM に結果が先に入る、等 |
| E2 | **虹を安売りしない**。虹の演出は「量」ではなく「質的断絶」（BGM停止・無音・合唱・時間歪み）で作る |
| E3 | **スキップを必ず用意**。ただし初回はフル演出。スキップしても結果の快感（ファンファーレ・NEW）は残す |
| E4 | **昇格の前には必ずタメ（無音）**。間を作らない昇格は驚きにならない |
| E5 | 同じ SFX を昇格の各段で使い回さない |
| E6 | 10連のめくりは **最良札を最後**。ソートを忘れると盛り上がりが中盤で終わる |
| E7 | 演出時間は「単発 6秒前後 / 10連 12秒前後」を上限に。長すぎると2回目から苦痛になる |
| E8 | 演出中に UI 操作を受け付けない時間を作らない（常にスキップ可能に）。ただし最後の 400ms は誤タップ防止で無効化 |
| E9 | **演出の中断（スキップ / 画面離脱）で状態が壊れないこと**。抽選は演出前に確定済み・保存済みにする |
| E10 | ヒットストップを 150ms 以上にしない（フリーズと誤認される） |
| E11 | 画面揺れは回転を少し混ぜる（並進だけだと安っぽい）。ただし酔い対策で最大 1.2° まで |
| E12 | フラッシュは **1フレーム全白 → 指数減衰**。長い白は不快 |

## F. 状態・セーブ

| # | ルール |
|---|---|
| F1 | セーブは **バージョン付き**。`{v: 3, data: {...}}`。読み込み時に順次マイグレーション |
| F2 | JSON パース失敗・想定外の型は **握りつぶして初期状態にフォールバック**（クラッシュさせない） |
| F3 | localStorage が使えない環境（プライベートモード等）でもメモリ上で動作継続 |
| F4 | **抽選結果は演出の前に確定・保存**。演出中にリロードされても結果は失われない（「演出中に閉じたら石が消えた」を防ぐ） |
| F5 | 書き込みは 300ms デバウンス。ただし抽選直後は即時 flush |
| F6 | データ削除は 2段階確認 |

## G. コード品質

| # | ルール |
|---|---|
| G1 | 外部依存ゼロ。ビルド不要。`index.html` を開けば動く（`file://` でも可能な限り動くよう配慮するが、ES Modules は http 必須なので簡易サーバ手順を README に書く） |
